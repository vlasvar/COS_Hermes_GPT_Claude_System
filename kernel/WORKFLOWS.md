# Canonical workflows

## 1. Bootstrap a workspace

1. Read `00_START_HERE.md` and its referenced System files.
2. Find the native `COS_DATABASE` Google Sheet.
3. Read `System Check`.
4. Write a harmless test value and read it back.
5. Add an Agent Log entry and read it back.
6. Continue only when actual connector capability is known.

If the connector is read-only, explain the limitation and stop. Do not substitute a simulated success.

## 2. Complete finance-first onboarding

Follow `FINANCE_FIRST.md`. Ask only for primary currency, initial period, finance scope, and budget period before requesting evidence. Identity is optional.

## 3. Process an inbox item

1. Capture the source, received time, and a concise neutral summary.
2. Check for duplicates and links to existing records.
3. Classify it as reference, Action, Project, Commitment, Decision, Contact update, or unresolved.
4. Propose the smallest necessary record changes.
5. Apply the approval policy.
6. Execute only authorized steps.
7. Link evidence and write an Agent Log entry.
8. Mark the Inbox item processed only after its destination records exist.

## 4. Manage a project

1. Express the project as a verifiable desired outcome.
2. Assign an owner and review date.
3. Link at least one next Action or mark the project blocked.
4. Record relevant Commitments and Decisions.
5. During review, close, continue, pause, or cancel explicitly.

## 5. Record a decision

1. State the question being decided.
2. Record the selected option and date.
3. Capture concise rationale and known trade-offs.
4. Add a revisit trigger when the decision depends on changeable assumptions.
5. Link affected Projects, Actions, and evidence.

## 6. Prepare an external communication

1. Identify the recipient, purpose, channel, and desired outcome.
2. Draft using only authorized context.
3. Separate confirmed facts from assumptions.
4. Request approval unless delegated in the private policy.
5. Send through the approved channel.
6. Verify delivery when possible and log the result.

## 7. Weekly review

1. Clear or classify every remaining Inbox item.
2. Find overdue Actions and Commitments.
3. Ensure every active Project has a next Action or blocker.
4. Review pending approvals and unresolved conflicts.
5. Revisit Decisions whose trigger has fired.
6. Identify the top outcomes for the next period.
7. Store a Review record and create resulting Actions.
